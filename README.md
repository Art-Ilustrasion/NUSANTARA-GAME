# 🏝 Jelajah Nusantara — Game Interaktif Pulau Indonesia

Game edukasi interaktif tentang pulau-pulau besar Indonesia. Dibuat dengan HTML, CSS, dan JavaScript murni — tidak butuh framework atau instalasi apapun.

## 🎮 Fitur Game

### 🎯 Kuis Cepat
10 soal pilihan ganda tentang fakta geografi, fauna, dan karakteristik pulau-pulau di Indonesia. Setiap jawaban benar mendapat +10 poin.

### 🔗 Jodohkan
Cocokkan 7 pulau besar Indonesia dengan fakta uniknya masing-masing. Klik pulau di kiri, lalu klik fakta yang sesuai di kanan.

### 🔍 Tebak Pulau
Baca petunjuk satu per satu lalu tebak nama pulaunya. Makin sedikit petunjuk yang digunakan, makin besar poin yang didapat (maksimal +4 poin).

## 🚀 Cara Menjalankan

### Lokal
Cukup buka file `index.html` di browser — tidak perlu server, tidak perlu instalasi.

### GitHub Pages
1. Upload repository ini ke GitHub
2. Masuk ke **Settings → Pages**
3. Pilih branch `main` dan folder `/ (root)`
4. Klik **Save** — game otomatis live di:
   `https://<username>.github.io/<nama-repo>/`
